TG-07 OPERATING MANUAL & SHORTCUTS

01 // CORE PARADIGM: LATCH & QUANTIZED PRE-INPUT (CUE)

일반적인 신디사이저처럼 건반을 계속 누르고 있을 필요가 없습니다. LATCH ON 상태에서는 코드를 한 번 누르면 손을 떼도 소리가 유지되며, 음악이 연주되는 도중 다음 코드를 언제든 미리 누르면(Pre-input) 새 코드가 즉시 연주되지 않고 NEXT GRID PRE-INPUT (CUE) 슬롯에 대기합니다. 마스터 클락의 다음 마디(Grid)가 시작되는 순간 7개의 보이스가 최단 경로로 우아하게 미끄러집니다.

02 // COMPUTER KEYBOARD SHORTCUTS

ROOT PITCH CONTROLS

  • Z ~ M 피아노 건반 방식 12개 반음 순차 매핑
  • Z X C V B N M 흰건반 (C, D, E, F, G, A, B)
  • S D G H J 검은건반 (C♯, D♯, F♯, G♯, A♯)

GLOBAL & TRANSPORT

  • Space 자동 루프 재생 / 전체 릴리즈 (Stop)
  • ? / / 이 사용 설명서 / 단축키 팝오버 열기/닫기
  • Esc 팝오버 닫기

24 HARMONIC VOICING KEYS

ROW 1 (1~=) 1:maj2:m3:sus24:sus45:dim6:aug 7:add98:69:m60:6/9-:7sus4=:dim7
ROW 2 (Q~]) Q:maj7W:m7E:7R:m7♭5T:maj9Y:m9 U:9I:m11O:13P:7♭9[:7♯9]:maj7♯11

03 // WEBMIDI ROUTING MODES

  • ROOT ONLY (기본값): 건반의 아무 키나 단음으로 누르면 그 음이 Root로 지정되며, 현재 선택된 코드 성향으로 다음 Grid에 선입력되어 글라이드합니다. (베이스 치듯 연주 가능)
  • SPLIT (Swan Glide 원작): C3 미만은 Root 선택, C3 이상은 24가지 코드 타입 선택용으로 건반을 분할합니다.
  • POLY CHORD DETECT: 건반으로 3~4개 음의 코드를 직접 연주하면 실시간으로 화성을 분석하여 자동 선입력합니다.

04 // GLIDE CURVE & VOICE MOTION

  • START ON GRID vs LAND ON GRID: 다음 마디 첫 박(Beat 1)에 글라이드를 시작할지, 아니면 다음 마디 첫 박에 딱 도착하도록 미리 출발할지 선택할 수 있습니다.
  • EXP OUT: 아날로그 RC 회로 질감처럼 초반에 빠르게 출발하여 목적 음정에 부드럽게 안착합니다.
  • STRUM ↑ / ↓: 7개 성부가 동시에 출발하지 않고 아르페지오처럼 시차(Strum Delay)를 두고 순차 출발합니다.
  • ARP WAVE: 코드가 길게 유지되는 동안에도 8분음표 단위로 내부 성부들이 인접한 코드 구성음 사이를 오가며 물결치듯 움직입니다.
